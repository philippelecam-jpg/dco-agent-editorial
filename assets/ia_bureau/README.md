# Mina et Nino : références V2

Quatre portraits originaux de personnages fictifs, générés avec l'outil de génération d'images puis enregistrés en JPEG pour le pipeline :

- `mina-realiste-v2.jpg` : femme d'environ 40 ans, carré auburn, lunettes ambrées, veste bleu pétrole et chemisier crème.
- `nino-realiste-v2.jpg` : homme d'environ 32 ans, peau mate, cheveux noirs bouclés, barbe légère, pull ocre.
- `mina-anime-v2.jpg` et `nino-anime-v2.jpg` : déclinaisons dessinées des mêmes portraits, contours éditoriaux, palette crème/pétrole/ocre.

Consigne commune : une seule personne assise à une table de réunion, visage presque frontal, éclairage naturel net, cadrage vertical, sans texte, logo, voile blanc ni autre visage. Les variantes dessinées utilisent les portraits réalistes comme référence d'identité. Les voix sont définies dans le scénario, jamais déduites du portrait par le générateur vidéo.
